# جک؛ دستیار تحلیل پرتفوی

پروژهٔ شخصی برای اجرا روی کامپیوتر محل کار یا لپ‌تاپ منزل. معماری شامل هستهٔ جمع‌آوری و تحلیل با پایتون و هستهٔ نمایش HTML روی localhost است. سامانهٔ بورسی API ندارد و دریافت اطلاعات از مرورگر پس از ورود دستی کاربر طراحی می‌شود.

## وضعیت فعلی

مستندات، اسکیل‌ها و نسخه‌های فارسی، ابزار ساخت سند، تنظیمات محلی و مقدمات کار روی دو دستگاه آماده‌اند. سرور برنامه، داشبورد و دریافت واقعی پرتفوی هنوز پیاده‌سازی نشده‌اند.

## دریافت روی دستگاه دوم

```powershell
git clone https://github.com/bahrami05-meh/Automation.git F:\Automasion
cd F:\Automasion
.\setup-local.ps1
```

فرمان clone فقط زمانی استفاده شود که پوشهٔ مقصد موجود نیست یا خالی است. در نسخهٔ موجود پروژه ابتدا وضعیت تغییرات بررسی شود و سپس `git pull --ff-only` انجام شود؛ پوشهٔ موجود بازنویسی نشود.

Python 3.12 و Git برای آماده‌سازی لازم‌اند. راه‌اندازی محیط محلی به معنی اجرای برنامه نیست؛ برنامه هنوز ساخته نشده است.

## مستندات

- `PROJECT.md`: تصمیم‌ها و معماری.
- `TWO-DEVICE.md`: راه‌اندازی و جابه‌جایی بین دو دستگاه.
- `مستند-پروژه-جک.docx`: سند Word پروژه.
- `skills/`: پنج اسکیل و فایل‌های فارسی `Fa-SKILL.md`.

## بررسی مقدمات

```powershell
.\.venv\Scripts\python.exe .\check-local.py
.\.venv\Scripts\python.exe -m unittest discover -s tests -v
```

## اطلاعات خصوصی

تنظیمات واقعی دستگاه، محیط مجازی، اطلاعات ورود، نشست مرورگر، داده‌های واقعی پرتفوی، گزارش‌های شخصی و پشتیبان‌ها محلی می‌مانند و نباید در مخزن ثبت شوند. هر دستگاه ورود مستقل دارد. GitHub برای انتقال کد و مستندات است؛ تاریخچهٔ خصوصی خودکار همگام نمی‌شود.

در پایان هر مرحله، فایل‌های مرتبط و فاقد اطلاعات حساس بررسی، ثبت و ارسال شوند. منابع و مجوزهای اسکیل‌های کپی‌شده داخل پوشه‌های آن‌ها حفظ شده‌اند.
