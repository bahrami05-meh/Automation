# جک؛ دستیار تحلیل پرتفوی

پروژهٔ شخصی برای اجرا روی کامپیوتر محل کار یا لپ‌تاپ منزل. معماری شامل هستهٔ جمع‌آوری و تحلیل با پایتون و هستهٔ نمایش HTML روی localhost است. سامانهٔ بورسی API ندارد و دریافت اطلاعات از مرورگر پس از ورود دستی کاربر طراحی می‌شود.

## وضعیت فعلی

نسخهٔ اولیهٔ قابل‌اجرا آماده است: سرور Python فقط روی localhost، داشبورد فارسی و تحلیل نمونه بدون دادهٔ شخصی. دریافت واقعی پرتفوی و اتصال مرورگر هنوز پیاده‌سازی نشده‌اند.

## اجرای نسخهٔ اولیه

```powershell
.\.venv\Scripts\python.exe .\backend\server.py
```

سپس آدرس `http://127.0.0.1:8765` را در مرورگر باز کنید. داشبورد فقط دادهٔ نمونه نشان می‌دهد، سفارش مالی ارسال نمی‌کند و هیچ اطلاعات کارگزاری را ذخیره نمی‌کند.

## دریافت روی دستگاه دوم

```powershell
git clone https://github.com/bahrami05-meh/Automation.git F:\Automasion
cd F:\Automasion
.\setup-local.ps1
```

فرمان clone فقط زمانی استفاده شود که پوشهٔ مقصد موجود نیست یا خالی است. در نسخهٔ موجود پروژه ابتدا وضعیت تغییرات بررسی شود و سپس `git pull --ff-only` انجام شود؛ پوشهٔ موجود بازنویسی نشود.

Python 3.12 و Git برای آماده‌سازی لازم‌اند.

## مستندات

- `PROJECT.md`: تصمیم‌ها و معماری.
- `TWO-DEVICE.md`: راه‌اندازی و جابه‌جایی بین دو دستگاه.
- `مستند-پروژه-جک.docx`: سند Word پروژه.
- `skills/`: پنج اسکیل و فایل‌های فارسی `Fa-SKILL.md`.
