# جک؛ دستیار تحلیل پرتفوی

پروژهٔ شخصی برای اجرا روی کامپیوتر محل کار یا لپ‌تاپ منزل. معماری شامل هستهٔ جمع‌آوری و تحلیل با پایتون و هستهٔ نمایش HTML روی localhost است. سامانهٔ بورسی API ندارد و دریافت اطلاعات از مرورگر پس از ورود دستی کاربر طراحی می‌شود.

## وضعیت فعلی

نسخهٔ اولیهٔ قابل‌اجرا آماده است: سرور Python فقط روی localhost، داشبورد فارسی و تحلیل نمونه بدون دادهٔ شخصی. دریافت واقعی پرتفوی و اتصال مرورگر هنوز پیاده‌سازی نشده‌اند.

## اجرای نسخهٔ اولیه

```powershell
.\.venv\Scripts\python.exe .\backend\server.py
```

سپس آدرس `http://127.0.0.1:8765` را در مرورگر باز کنید. نام نماد از داخل داشبورد وارد می‌شود. تا زمانی که ماژول دریافت دادهٔ بازار و خواندن مرورگر ساخته نشود، نماد انتخاب‌شده با `DATA_BLOCKED` گزارش می‌شود؛ داشبورد داده حدس نمی‌زند، سفارش مالی ارسال نمی‌کند و اطلاعات کارگزاری را ذخیره نمی‌کند.

هستهٔ اعتبارسنجی دادهٔ بازار نیز آماده است: در بخش «ورود دادهٔ بازار از منبع تأییدشده»، یک بستهٔ JSON با منبع HTTPS، زمان `Asia/Tehran`، واحد `IRR` یا `IRT`، نوع قیمت و حداقل ۲۱ ردیف OHLCV وارد کنید. فقط میزبان‌های فهرست `market.approved_source_hosts` در `config.local.toml` پذیرفته می‌شوند. این مسیر برای آزمون هسته و آماده‌سازی اتصال آینده به ایجنت مرورگر است؛ داده در این نسخه ذخیره نمی‌شود.

«ایجنت دریافت» و پس از آن «ایجنت تکنیکال» فعال‌اند و هر اجرا را با شناسهٔ اجرا در گزارش نشان می‌دهند. ایجنت تکنیکال فقط پس از اعتبارسنجی موفق، هم‌جهتی یا اختلاف روند SMA و مومنتوم RSI را با شواهد ثبت می‌کند؛ نتیجهٔ آن پیشنهاد معامله نیست و `WATCHLIST` را تغییر نمی‌دهد. قراردادها در `agents/market-capture.md` و `agents/technical-analysis.md` قرار دارند.

## دریافت روی دستگاه دوم

```powershell
git clone https://github.com/bahrami05-meh/Automation.git F:\Automasion
cd F:\Automasion
.\setup-local.ps1
```

فرمان clone فقط زمانی استفاده شود که پوشهٔ مقصد موجود نیست یا خالی است. در نسخهٔ موجود پروژه ابتدا وضعیت تغییرات بررسی شود و سپس `git pull --ff-only` انجام شود؛ پوشهٔ موجود بازنویسی نشود.

Python 3.12 و Git برای آماده‌سازی لازم‌اند.
