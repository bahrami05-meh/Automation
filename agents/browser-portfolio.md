# قرارداد ایجنت مرورگر و پرتفوی

## هویت

- نام نمایشی: ایجنت مرورگر و پرتفوی
- شناسهٔ فنی: `browser-portfolio-agent`
- نسخهٔ اولیه: `0.1`

## مرز مسئولیت

این ایجنت مرز فقط‌خواندنی ورود دادهٔ قابل‌مشاهدهٔ پرتفوی است. ورود به کارگزاری، نام کاربری، رمز، OTP، CAPTCHA، کوکی و نشست با کاربر است و هرگز به دادهٔ ورودی، گزارش، فایل پروژه یا GitHub راه ندارند.

## قرارداد مشاهدهٔ پرتفوی

ورودی `portfolio_observation` فقط در حافظهٔ همان درخواست اعتبارسنجی می‌شود و ذخیره نمی‌شود. فیلدهای لازم: `source`، `collected_at`، `timezone=Asia/Tehran`، `price_unit=IRR|IRT` و حداقل یک ردیف `holdings`. هر ردیف شامل `symbol`، `quantity`، `average_price`، `last_price` و `market_value` است.

میزبان `source` باید HTTPS و در `brokerage.approved_hosts` فایل خصوصی `config.local.toml` ثبت شده باشد. فهرست پیش‌فرض Git خالی است؛ نام کارگزاری یا دادهٔ پرتفوی خصوصی در مخزن ثبت نمی‌شود.

## خروجی

- `WAITING_FOR_BROWSER_SOURCE`: هنوز پل مرورگر یا مشاهدهٔ فقط‌خواندنی به اجرا وصل نشده است.
- `PORTFOLIO_CAPTURED`: دادهٔ قابل‌نمایش پرتفوی اعتبارسنجی شده است.
- `PORTFOLIO_BLOCKED`: منبع، زمان، واحد، ساختار ردیف‌ها یا حریم خصوصی نامعتبر است.

## محدودیت نسخهٔ اولیه

این نسخه هنوز Chrome یا سایت کارگزاری را باز و کنترل نمی‌کند؛ فقط قرارداد امن و اعتبارسنجی دادهٔ قابل‌مشاهده را ایجاد می‌کند. اتصال عملی به مرورگر در مرحلهٔ بعد، فقط با ورود دستی کاربر و میزبان تأییدشده انجام می‌شود. هیچ سفارش یا اقدام مالی در این ایجنت وجود ندارد.
