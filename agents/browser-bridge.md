# قرارداد پل مرورگر

مسیر محلی `POST /api/browser-observation` دادهٔ ساخت‌یافتهٔ خوانده‌شده از Chrome را می‌پذیرد. ورود و احراز هویت فقط با کاربر انجام می‌شود؛ پل هر کلیدی شامل رمز، OTP، نشست، کوکی، توکن یا نام کاربری را رد می‌کند و HTML خام را نمی‌پذیرد.

بدنه باید شامل `symbol` و `market_snapshot` معتبر باشد و می‌تواند `chart_observation`، `market_board_observation`، `fundamental_observation`، `risk_observation` و `portfolio_observation` را نیز داشته باشد. پس از اعتبارسنجی، زنجیرهٔ ایجنت دریافت، تکنیکال، کنترل نمودار، تابلو، بنیادی، ریسک، ناظر کیفیت و مرورگر/پرتفوی اجرا می‌شود. این مسیر فقط localhost است و سفارش مالی ندارد.
