# خوانندهٔ Chrome

این پوشه یک افزونهٔ Manifest V3 برای خواندن فقط‌خواندنی صفحه‌های مجاز است. پس از ورود دستی کاربر، خواننده فقط جدول‌ها و متن قابل‌مشاهده را بررسی می‌کند و هیچ رمز، OTP، کوکی، توکن یا نشست را استخراج نمی‌کند.

## نصب محلی

در Chrome به `chrome://extensions` بروید، Developer mode را فعال کنید و `Load unpacked` را روی همین پوشه بزنید. این نصب نیازمند تأیید کاربر است.

## اجرا

پس از آماده‌شدن صفحه، در همان صفحه این فرمان را اجرا کنید:

```js
window.postMessage({type: 'JACK_READ_MARKET'}, location.origin)
```

خواننده فقط وقتی یک جدول دارای عنوان‌های `date, open, high, low, close, volume` (یا معادل‌های فارسی تعریف‌شده در کد) و حداقل ۲۱ ردیف معتبر باشد، داده را می‌فرستد. ترتیب ستون‌ها از عنوان‌ها خوانده می‌شود؛ تاریخ‌ها باید معتبر و یکتا باشند و ترتیب صعودی یا نزولی داشته باشند. دادهٔ نزولی پیش از تحلیل به ترتیب زمانی تبدیل می‌شود. مقدار خالی، `N/A`، عدد نامتناهی، متن غیرعددی و کندل ناسازگار مسدود می‌شوند؛ حجم صفر معتبر است.

## قرارداد adapter منبع

جدول باید مشخصات زیر را صریحاً از adapter تأییدشدهٔ همان منبع دریافت کند:

```html
<table data-jack-symbol="TEST" data-jack-price-unit="IRR"
       data-jack-price-type="raw" data-jack-timeframe="daily"
       data-jack-date-format="iso">
```

این مشخصات از حدس یا پیش‌فرض ساخته نمی‌شوند. فعلاً adapter زندهٔ تأییدشده برای TSETMC یا EasyTrader وجود ندارد؛ روی صفحات فاقد این مشخصات، خواننده `OHLCV_NOT_RECOGNIZED` می‌دهد و ارسال مسدود است. این قرارداد اثبات اصالت داده یا احراز هویت صفحه نیست. سرور Origin را با میزبان‌های مصوب بازار بررسی می‌کند. schema تو در تو هنوز تکمیل نشده است. وضعیت تلاش برای اتصال زنده در `STAGE-3-OBSERVATION-FRESHNESS.md` ثبت شده است.

## nonce یک‌بارمصرف پل

خواننده پیش از هر ارسال، از `GET /api/browser-nonce` یک nonce تازه می‌گیرد و در فیلد `bridge_nonce` همراه داده می‌فرستد. nonce فقط در حافظهٔ سرور، برای حداکثر ۶۰ ثانیه نگهداری می‌شود؛ به Origin صادرکننده متصل است و فقط یک بار مصرف می‌شود. درخواست بدون nonce، با nonce نامعتبر، منقضی یا مصرف‌شده با HTTP 400 و `DATA_BLOCKED` رد می‌شود. Origin ناشناخته برای دریافت nonce یا ارسال داده HTTP 403 می‌گیرد.

این سازوکار احراز هویت کاربر یا افزونه نیست؛ صفحات Origin مجاز نیز می‌توانند nonce دریافت کنند. کلاینت محلی بدون هدر Origin برای آزمایش پشتیبانی می‌شود و nonce آن فقط در درخواست بدون Origin پذیرفته می‌شود. nonce در خروجی تحلیل به صفحه بازگردانده نمی‌شود و در گزارش‌ها یا فایل‌ها ذخیره نمی‌شود. وضعیت کامل در `STAGE-4-BROWSER-NONCE.md` ثبت شده است.

تغییرات پروتکل پس از راه‌اندازی مجدد سرور و بارگذاری مجدد افزونه فعال می‌شوند. در این مرحله سرویس یا افزونهٔ نصب‌شدهٔ کاربر تغییر داده نشده است.

آزمون parser: `node --test tests/test_browser_reader.cjs` از ریشهٔ پروژه. این آزمون fixtureهای DOM شبیه‌سازی‌شده را پوشش می‌دهد و جایگزین آزمون صفحهٔ زنده نیست.
