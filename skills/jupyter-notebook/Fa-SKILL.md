# اسکیل دفترچهٔ ژوپیتر

شناسهٔ اسکیل: `jupyter-notebook`

شرح: برای درخواست ساخت، ایجاد ساختار اولیه یا ویرایش دفترچه‌های ژوپیتر با پسوند `.ipynb` برای آزمایش، بررسی اکتشافی یا آموزش استفاده شود. قالب‌های همراه ترجیح داده شوند و برای ساخت دفترچهٔ اولیهٔ مرتب، اسکریپت `new_notebook.py` اجرا شود.

این فایل ترجمهٔ فارسی `SKILL.md` برای مطالعه و آرشیو است. فرمان‌های نمونه و شناسه‌ها برای حفظ قابلیت استفاده، به صورت اصلی باقی مانده‌اند. مسیرهای پیش‌فرض زیر متعلق به متن اصلی‌اند؛ نسخهٔ این پروژه در `F:\Automasion\skills\jupyter-notebook` قرار دارد و خروجی پروژه باید داخل `F:\Automasion` ذخیره شود.

دفترچه‌های مرتب و قابل‌بازتولید را برای دو حالت اصلی ایجاد کنید:

- آزمایش و تحلیل اکتشافی.
- آموزش و توضیح گام‌به‌گام با هدف یادگیری.

برای ساختار یکدست و کاهش خطای JSON، قالب‌ها و اسکریپت همراه را ترجیح دهید.

## زمان استفاده

- ساخت دفترچهٔ `.ipynb` جدید از ابتدا.
- تبدیل یادداشت‌های اولیه یا اسکریپت‌ها به دفترچهٔ ساختاریافته.
- بازآرایی دفترچهٔ موجود برای بازتولیدپذیری و مرور آسان‌تر.
- ساخت آزمایش یا آموزشی که دیگران آن را می‌خوانند یا دوباره اجرا می‌کنند.

## درخت تصمیم

- درخواست اکتشافی، تحلیلی یا فرضیه‌محور: `experiment`.
- درخواست آموزشی، گام‌به‌گام یا متناسب با مخاطب خاص: `tutorial`.
- ویرایش دفترچهٔ موجود: بازآرایی با حفظ هدف و بهبود ساختار.

## مسیر اسکیل؛ یک‌بار تنظیم شود

نمونهٔ اصلی برای پوستهٔ Bash:

```bash
export CODEX_HOME="${CODEX_HOME:-$HOME/.codex}"
export JUPYTER_NOTEBOOK_CLI="$CODEX_HOME/skills/jupyter-notebook/scripts/new_notebook.py"
```

در تنظیم پیش‌فرض متن اصلی، اسکیل‌های کاربر در `$CODEX_HOME/skills` و به‌طور پیش‌فرض در `~/.codex/skills` نصب می‌شوند.

## گردش کار

### ۱. هدف را مشخص کنید

نوع دفترچه را `experiment` یا `tutorial` تعیین کنید. هدف، مخاطب و معیار تکمیل را ثبت کنید.

### ۲. ساختار را از قالب بسازید

برای پرهیز از نوشتن دستی JSON خام دفترچه از اسکریپت کمکی استفاده کنید.

```bash
uv run --python 3.12 python "$JUPYTER_NOTEBOOK_CLI" \
  --kind experiment \
  --title "Compare prompt variants" \
  --out output/jupyter-notebook/compare-prompt-variants.ipynb
```

عنوان نمونهٔ اول به معنی «مقایسهٔ نسخه‌های مختلف دستور» است.

```bash
uv run --python 3.12 python "$JUPYTER_NOTEBOOK_CLI" \
  --kind tutorial \
  --title "Intro to embeddings" \
  --out output/jupyter-notebook/intro-to-embeddings.ipynb
```

عنوان نمونهٔ دوم به معنی «آشنایی با بازنمایی‌های برداری» است.

### ۳. دفترچه را با گام‌های کوچک و قابل‌اجرا کامل کنید

هر سلول کد روی یک گام متمرکز باشد. سلول‌های کوتاه Markdown هدف و نتیجهٔ موردانتظار را توضیح دهند. وقتی خلاصهٔ کوتاه کافی است، از خروجی‌های حجیم و شلوغ پرهیز کنید.

### ۴. الگوی مناسب را اعمال کنید

برای آزمایش از `references/experiment-patterns.md` و برای آموزش از `references/tutorial-patterns.md` پیروی کنید.

### ۵. دفترچهٔ موجود را با احتیاط ویرایش کنید

ساختار را حفظ کنید و ترتیب سلول‌ها را فقط هنگامی تغییر دهید که روایت از بالا به پایین بهتر شود. ویرایش هدفمند بر بازنویسی کامل ترجیح دارد. اگر ویرایش JSON خام لازم است، ابتدا `references/notebook-structure.md` را بخوانید.

### ۶. نتیجه را اعتبارسنجی کنید

اگر محیط اجازه می‌دهد، دفترچه را از ابتدا تا انتها اجرا کنید. اگر اجرا ممکن نیست، صریحاً اعلام کنید و روش اعتبارسنجی محلی را توضیح دهید. از فهرست کنترل نهایی در `references/quality-checklist.md` استفاده کنید.

## قالب‌ها و اسکریپت کمکی

- قالب‌ها در `assets/experiment-template.ipynb` و `assets/tutorial-template.ipynb` هستند.
- اسکریپت کمکی، قالب را بارگذاری می‌کند، سلول عنوان را به‌روز می‌کند و دفترچه را می‌نویسد.
- مسیر اسکریپت: `$JUPYTER_NOTEBOOK_CLI`؛ مسیر نصب پیش‌فرض متن اصلی: `$CODEX_HOME/skills/jupyter-notebook/scripts/new_notebook.py`.

## قرارداد فایل موقت و خروجی

- فایل‌های میانی در `tmp/jupyter-notebook/` قرار گیرند و پس از پایان حذف شوند.
- خروجی نهایی هنگام کار در مخزن در `output/jupyter-notebook/` ذخیره شود.
- نام فایل پایدار و توصیفی باشد؛ مانند `ablation-temperature.ipynb`.

## وابستگی‌ها؛ فقط هنگام نیاز نصب شوند

برای مدیریت وابستگی، `uv` ترجیح دارد. بسته‌های اختیاری پایتون برای اجرای محلی دفترچه:

```bash
uv pip install jupyterlab ipykernel
```

اسکریپت ساخت اولیهٔ همراه فقط از کتابخانهٔ استاندارد پایتون استفاده می‌کند و وابستگی اضافی نمی‌خواهد.
